# 마고 타종 클라우드 동기화

같은 마고에듀 통합 클라우드 계정(아이디)으로 연결한 기기끼리 시간표·종소리·오늘 설정·울린 기록을 실시간으로 맞춰요.
PC(데스크톱)와 안드로이드가 이 문서의 형식을 똑같이 따라요.

- 서버 프로그램 ID는 `tajong` 하나예요. 목록의 `tajong-android`(안드로이드 내려받기 항목)도 데이터는 `tajong` 으로 맞춰요.
- **PC**: 통합 클라우드(런처)가 켜 줘요. 타종은 동기화 폴더(`MAGOEDU_DATA_DIR`)에 파일을 쓰고 읽기만 하고, 서버와 주고받는 일은 런처가 해요.
- **안드로이드**: 설정에서 통합 클라우드에 로그인하고, 앱이 서버의 동기화 API(`/api/sync/tajong…`)와 실시간 알림(`/api/sync/events`)을 직접 써요.

## 파일

동기화 폴더 안의 경로예요. 모두 UTF-8 JSON이고, 쓸 때는 `.tmp` 에 쓴 뒤 이름을 바꿔요(원자적 저장).

| 경로 | 누가 쓰나 | 내용 |
| --- | --- | --- |
| `config.json` | 아무 기기 | 시간표·세트·종소리 목록·지금 쓰는 세트 |
| `sounds/<file_name>` | 아무 기기 | 종소리 파일 (`file_name` 은 폴더 없는 파일 이름) |
| `state.json` | 아무 기기 | 잠시 멈춤, 오늘 쉬기, 다음 종 건너뛰기, 다른 기기에 울려 달라는 요청 |
| `logs/<기기 ID>.json` | 그 기기만 | 그 기기가 남긴 기록(최근 60일) |

### `config.json`

백업 파일의 `data.json` 과 같은 내용에 머리말을 붙인 거예요.

```json
{
  "app": "MaplTajong",
  "kind": "config",
  "format": 1,
  "sounds": [{ "id": 1, "name": "bell1", "file_name": "bell1.wav", "volume": 1.0, "created_at": "2026-11-01 00:00:00" }],
  "schedule_sets": [{ "id": 1, "name": "기본", "created_at": "2026-11-01 00:00:00" }],
  "schedules": [
    { "id": 1, "set_id": 1, "name": "1교시", "weekday_mask": 31, "time_hhmm": "09:00", "sound_id": 1,
      "volume_override": null, "enabled": 1, "sort_order": 0, "created_at": "...", "updated_at": "..." }
  ],
  "settings": { "active_set_id": "1" },
  "meta": { "device_id": "…", "device_name": "교무실 PC", "at": "2026-11-01T00:00:00Z" }
}
```

- 줄은 `id` 순서로 써요. ID는 모든 기기가 같은 값을 써요(받은 `config.json` 의 ID를 그대로 넣음).
- `meta` 는 누가 언제 바꿨는지 보여 주는 용도예요. 내용이 바뀌었는지 볼 때는 `meta` 를 빼고 비교해요.

### `state.json`

```json
{
  "app": "MaplTajong",
  "kind": "state",
  "format": 1,
  "paused": false,
  "overrides": [
    { "date": "2026-11-01", "schedule_id": 3, "action": "SKIP_ONCE", "note": "admin" },
    { "date": "2026-11-02", "schedule_id": 0, "action": "PAUSE_DAY", "note": "admin" }
  ],
  "ring_requests": [
    { "id": "8c0f…", "schedule_id": 3, "sound_id": null, "at": "2026-11-01T01:23:45Z", "by": "기기 ID", "by_name": "원장님 폰" }
  ],
  "meta": { "device_id": "…", "device_name": "…", "at": "…" }
}
```

- `paused`: 홈의 "잠시 멈추기". 모든 기기가 함께 멈춰요.
- `overrides`: **오늘과 그 뒤 날짜**의 `SKIP_ONCE`(다음 종 건너뛰기), `PAUSE_DAY`(오늘 쉬기, `schedule_id` 0)만 넣어요.
  `FIRED_ONCE`(이미 울림 표시)는 기기마다 따로 두고 이 파일에 넣지 않아요.
- `ring_requests`: 종을 울리지 않는 기기에서 "지금 울리기"를 누르면 여기에 요청을 넣어요.
  - `schedule_id` 가 있으면 그 시간표의 종을, 없으면 `sound_id` 의 종소리를 울려요.
  - `at` 은 UTC ISO 8601 이에요. 쓸 때 10분이 지난 요청은 지워요.
  - 종을 울리는 기기는 처음 보는 요청 중 `at` 이 지금 ±2분 안인 것만 한 번 울리고, 처리한 `id` 를 이 기기에만 기억해요.
    시간표 요청이면 그 기기에 `FIRED_ONCE`(forced)를 남기고, 기록은 `PLAYED` / 설명 `forced · <by_name>` 으로 남겨요.

### `logs/<기기 ID>.json`

```json
{
  "app": "MaplTajong",
  "kind": "logs",
  "format": 1,
  "device_id": "…",
  "device_name": "교무실 PC",
  "logs": [
    { "occurred_at": "2026-11-01 09:00:00", "schedule_id": 1, "schedule_name": "1교시", "sound_name": "bell1",
      "result": "PLAYED", "detail": "" }
  ]
}
```

- 각 기기는 **자기 파일만** 써요. 기록을 남긴 뒤 몇 초 모아서(5초 정도) 다시 써요. 최근 60일, 많아야 5,000줄.
- `occurred_at` 은 그 기기의 현지 시각 `YYYY-MM-DD HH:MM:SS` 예요.
- 기록 화면과 홈의 "오늘 결과"는 내 기록과 다른 기기 파일을 합쳐서 보여 주고, 어느 기기 기록인지 함께 보여 줘요.
- 기기 ID는 파일 이름에 쓰니 `A-Z a-z 0-9 _ -` 만 남겨요. PC는 실행 허가증의 `dev`, 안드로이드는 로그인할 때 보낸 기기 ID예요.

## 언제 쓰고 언제 읽나

- **쓰기**: 사용자가 공유 데이터(시간표·세트·종소리·지금 세트 / 멈춤·건너뛰기·오늘 쉬기·울리기 요청)를 바꾸면
  1초쯤 모아서 그 파일을 다시 만들고, **내용(`meta` 제외)이 마지막으로 맞춘 것과 다를 때만** 써요.
- **읽기**: 다른 기기에서 바뀐 파일이 오면 바로 적용해요. 적용한 직후의 내용을 "마지막으로 맞춘 것"으로 기억해서,
  적용 때문에 다시 쓰는 일(주고받기 되풀이)이 없게 해요.
- **종소리 파일**: 새 종소리는 파일을 먼저 쓰고 나서 `config.json` 을 써요. 받는 쪽은 파일이 아직 안 와도 괜찮게 처리해요
  (울릴 때 파일을 다시 찾음). 종소리를 지우면 파일도 지워요.
- `config.json` 을 적용할 때:
  - 시간표·세트·종소리 줄을 파일 내용으로 바꿔요(ID 그대로). 종소리 파일은 따로 오니 건드리지 않아요.
  - 이 기기의 `FIRED_ONCE`·`SKIP_ONCE` 중 **시간표가 없어졌거나 시각이 바뀐 것만** 지워요. 나머지는 그대로 둬요(같은 분에 두 번 울리지 않게).
  - 기록(logs)과 이 기기 설정은 그대로 둬요.
- 같은 파일을 두 기기가 거의 동시에 바꾸면 **서버에 먼저 올라간 것**이 이겨요.
  PC는 밀린 파일을 런처가 `conflicts` 폴더에 보관하고, 안드로이드는 서버 것을 적용한 뒤 "다른 기기에서 먼저 바뀌어서 그 내용으로 맞췄어요"라고 알려요.

## 처음 연결할 때

- 클라우드에 `config.json` 이 없으면: 이 기기 데이터를 올려요.
  PC는 예전에 따로 설치해 쓰던 데이터(`%APPDATA%\MaplTajong`)가 있으면 그것을, 없으면 기본 종소리로 시작해요.
- 클라우드에 있고 이 기기에도 기본값이 아닌 데이터가 있으며 둘이 다르면, 고르게 해요:
  **클라우드 시간표 쓰기**(기본, 이 기기 것은 백업 파일로 남김) / **이 기기 시간표로 바꾸기**.

## 이 기기에서 종 울리기

- 설정 키 `ring_device` (`"1"`/`"0"`), **기기마다 따로**(동기화하지 않음).
- 기본값: PC는 켜짐. 안드로이드는 로그인 화면에서 고르고, 이 기기에서 처음 로그인할 때는 **꺼짐**
  (다시 로그인할 때는 지난번에 고른 값).
- 꺼져 있으면: 시간표의 종을 울리지 않고 기록도 남기지 않아요. `ring_requests` 도 처리하지 않아요.
  "지금 울리기"는 이 기기에서 울리는 대신 `ring_requests` 에 넣어요. 종소리 미리 듣기는 그대로 이 기기에서 나요.
- 안드로이드는 **로그인해야 앱을 쓸 수 있어요**(2.2.1부터). 로그인하지 않은 상태로 종을 울리는 일은 없어요.
  - 로그인하지 않았으면 로그인 화면만 보이고, 알람을 걸지 않아요(부팅·앱 업데이트 뒤에도). 앱 자체 업데이트는 그대로 돼요.
  - 한 번 로그인하면 인터넷이 없어도 그대로 쓰고 종도 울려요(세션 토큰은 기기에 남아 있음).
  - 로그아웃하거나 세션이 끝나면(401) 로그인 화면으로 돌아가고 알람을 지우고 클라우드 연결 서비스도 멈춰요.
    세션이 끝났을 때는 "로그인이 끝나서 이 기기에서 종을 울리지 않아요. 다시 로그인해 주세요." 알림을 띄워요.
  - 이 기기 시간표·종소리와 맞춘 기록은 지우지 않아요. 같은 계정으로 다시 로그인하면 이어서 맞추고,
    다른 계정이면 [처음 연결할 때](#처음-연결할-때)처럼 해요.

## 서버 실시간 알림

```
GET /api/sync/events?apps=tajong        Authorization: Bearer <세션 토큰>
→ 200 text/event-stream

event: hello
data: {"time":"2026-11-01T00:00:00Z"}

event: change
data: {"appId":"tajong","seq":123,"deviceId":"바꾼 기기 ID"}

: ping                                   (25초마다)
```

- 계정의 파일이 바뀌면(올리기·지우기·서버 정리) 그 계정의 연결에 `change` 를 보내요.
- 받으면 `GET /api/sync/tajong?since=<마지막 seq>` 로 바뀐 것만 받아요. 연결이 끊겼다 다시 붙으면 한 번 받아요.
- 다시 붙을 때는 1초에서 시작해 두 배씩, 많아야 30초 간격으로 해요.
