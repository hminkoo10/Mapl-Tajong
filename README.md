## 설치
2.2.0부터는 [마고에듀 통합 클라우드](https://mago.milky.kr)에서 설치하고 켜요. (따로 받는 설치 파일은 없어요)
- 통합 클라우드에 로그인한 뒤 프로그램 목록에서 ‘마고 타종’을 설치하고 ‘열기’를 누르면 돼요.
  바탕 화면 바로가기와 컴퓨터를 켜면 같이 켜기(‘함께 켜기’)도 통합 클라우드에서 정해요.
- 같은 아이디로 연결한 컴퓨터·휴대폰끼리 시간표, 세트, 종소리, 오늘 설정, 울린 기록을 맞춰요.
  종을 울리지 않을 기기는 설정 → 일반의 ‘이 기기에서 종 울리기’를 끄면 돼요.
- 예전에 `MaplTajong-Setup-x.y.z.exe`로 설치해 쓰던 컴퓨터는 처음 연결할 때 `%APPDATA%\MaplTajong`의
  시간표와 종소리를 그대로 옮겨 와요. 옮긴 뒤에는 예전 프로그램을 꺼 주세요. (켜 두면 종이 두 번 울려요)
